# Ex.No.10
Content Creation (Reports, Articles, Case Studies, etc.) Using Prompt Patterns

## Date: 01.09.26
## Reg. No.212224220081

## Aim:
To demonstrate how different Prompt Engineering techniques can be used to generate, improve, organize, and refine content such as reports, articles, and creative writing using an AI model.

The experiment focuses on understanding how prompt patterns such as Query Decomposition, Decision Making, Answer Engineering, Fact Check List, Tail Generation, Menu Actions, and Semantic Filtering can improve the quality, structure, clarity, and relevance of AI-generated content.

## Prompt Patterns Used
| Prompt Pattern | Purpose |
|---|---|
| Query Decomposition | Breaks a complex task into smaller tasks |
| Decision Making | Helps select the most suitable option |
| Answer Engineering | Controls the structure and format of the response |
| Fact Check List | Helps verify important information |
| Tail Generation | Extends existing content logically |
| Menu Actions | Provides different choices for the next action |
| Semantic Filter | Controls tone, style, and relevance |

## Test Case 1: Educational Report on Renewable Energy
# 1. Topic Selection

# Topic: Renewable Energy

# Objective

To create an educational report explaining renewable energy, its major sources, advantages, limitations, and importance in the future.

# 2. Basic Prompt
# Prompt
Write an educational report about renewable energy.
# First Draft Output

Renewable energy is energy obtained from naturally replenishing sources.

The major types of renewable energy include solar energy, wind energy, hydropower, biomass, and geothermal energy.

Renewable energy can help reduce dependence on fossil fuels and can support cleaner energy production.

Solar panels convert sunlight into electricity, while wind turbines use wind to generate electricity. Hydropower uses moving water to produce electricity.

Renewable energy has many benefits, but it also has challenges such as high initial costs, storage requirements, and dependence on environmental conditions.

# 3. Query Decomposition

Instead of asking the AI to create the complete report at once, the task is divided into smaller questions.

# Prompt
Create an educational report on renewable energy by completing these steps:

1. Define renewable energy.
2. Identify the major types.
3. Explain how each type works.
4. List important advantages.
5. Explain major limitations.
6. Discuss its importance for the future.
7. Create a short conclusion.

# Result

The response becomes more organized because the large task is divided into smaller sections.

# 4. Decision Making Pattern
# Prompt
Choose the three renewable energy sources that are most suitable
for explaining renewable energy to college students.

# Options:
A. Solar Energy
B. Wind Energy
C. Hydropower
D. Biomass
E. Geothermal Energy

Select three and explain why each was selected.
# AI Output

The selected sources are:

Solar Energy – easy to understand and widely used.
Wind Energy – demonstrates electricity generation using wind.
Hydropower – demonstrates the use of moving water for electricity generation.

The selection provides three different examples of renewable energy generation.

# 5. Answer Engineering Pattern
# Prompt
Write the renewable energy report using the following structure:

Title
Introduction
Meaning of Renewable Energy
Types of Renewable Energy
Advantages
Limitations
Future Importance
Conclusion

Use simple English.
Use short paragraphs and bullet points.
Keep the report suitable for college students.
# Improvement

The answer becomes easier to read because the required structure and writing style are clearly specified.

# 6. Fact Check List Pattern
# Prompt
Review the renewable energy report using this fact-check list:

1. Are renewable energy sources correctly identified?
2. Are the descriptions scientifically reasonable?
3. Are advantages and limitations balanced?
4. Are unsupported statistics removed?
5. Are assumptions clearly identified?
6. Are there any misleading statements?
7. Identify statements that should be verified before submission.
# Purpose

The fact-check prompt helps identify information that may require verification before using it in an academic report.

# 7. Tail Generation Pattern
# Prompt
Continue the renewable energy report from the section
"Future Importance".

Add two paragraphs explaining how renewable energy
can contribute to future energy systems.

Maintain the same educational tone and do not repeat
information already given.
# Result

The AI extends the existing report while maintaining the same topic, style, and logical flow.

# 8. Menu Actions Pattern
# Prompt
The renewable energy report is ready.

Choose one of the following actions:

A. Add an introduction
B. Add advantages and limitations
C. Add a conclusion
D. Simplify the language
E. Convert the report into presentation points

Select the most useful next action and explain the choice.
# Selected Action

# D. Simplify the language

# Reason

The report is intended for college students, so simple and clear language can improve readability.

# 9. Semantic Filter Pattern
# Prompt
Rewrite the renewable energy report using these filters:

Audience: College students
Tone: Educational and formal
Language: Simple English
Remove: Repeated information and unnecessary technical terms
Keep: Important facts, examples, advantages and limitations
Format: Clear headings and bullet points
# Result

The content becomes more suitable for the intended audience and removes unnecessary information.

# 10. Refined Content
# Renewable Energy – Educational Report
# Introduction

Renewable energy is energy produced from natural sources that are continuously replenished. It is an important alternative to conventional fossil fuels.

# Major Types
Solar Energy – uses sunlight to produce heat or electricity.
Wind Energy – uses wind turbines to generate electricity.
Hydropower – uses moving water to generate electricity.
Biomass Energy – uses organic materials as an energy source.
Geothermal Energy – uses heat from inside the Earth.
# Advantages
Reduces dependence on fossil fuels.
Uses naturally replenished resources.
Can reduce some forms of environmental pollution.
Supports the development of cleaner energy systems.
Can provide electricity in suitable locations.
# Limitations
Some renewable sources depend on weather conditions.
Energy storage can be challenging.
Initial installation costs can be high.
Suitable locations may be required for some systems.
# Future Importance

Renewable energy can play an important role in future energy systems. Improvements in energy storage, electricity networks, and renewable technologies can support wider adoption.

# Conclusion

Renewable energy provides important alternatives to fossil-fuel-based energy. Understanding its sources, benefits, and limitations helps students understand the transition toward cleaner energy systems.

# Test Case 2: Travel Blog Post
1. Topic Selection

Topic: Travel Blog – Exploring Ooty

Objective

To create an engaging travel blog using different prompt patterns while controlling its tone, structure, and content.

2. Basic Prompt
Prompt
Write a travel blog about Ooty.
First Draft Output

Ooty is a popular hill station in Tamil Nadu. It is known for its cool climate, green landscapes, tea plantations, and scenic surroundings.

Visitors can explore places such as Ooty Lake, Botanical Garden, and nearby viewpoints.

The town is suitable for people who enjoy nature, photography, sightseeing, and relaxing trips.

3. Query Decomposition
Prompt
Create a travel blog about Ooty by answering these smaller questions:

1. What is Ooty known for?
2. What places can visitors explore?
3. What activities can visitors do?
4. What type of food can visitors try?
5. What should a first-time visitor know?
6. Write a suitable conclusion.
Result

Breaking the task into smaller questions produces a more complete travel blog.

4. Decision Making Pattern
Prompt
Choose the best travel-blog theme for Ooty.

Options:

A. Nature and sightseeing
B. Adventure activities
C. Food-focused travel
D. Historical places

Select one theme and explain why it would be suitable
for a general travel audience.
Selected Theme

A. Nature and sightseeing

Reason

Ooty is widely associated with its hills, gardens, tea plantations, and scenic surroundings, making nature and sightseeing suitable themes for a general travel article.

5. Answer Engineering Pattern
Prompt
Write an Ooty travel blog using this structure:

Title
Introduction
Why Visit Ooty?
Places to Explore
Things to Do
Travel Tips
Conclusion

Tone: Friendly and informative
Audience: College students
Language: Simple English
Use short paragraphs and bullet points.
6. Fact Check List Pattern
Prompt
Review the travel blog using this checklist:

1. Are place names correct?
2. Are unsupported claims removed?
3. Are specific opening times avoided unless verified?
4. Are travel recommendations clearly presented as suggestions?
5. Are exaggerated statements removed?
6. Is the information suitable for a general audience?
Purpose

This helps reduce incorrect or unsupported information in the travel article.

7. Tail Generation Pattern
Prompt
Continue the Ooty travel blog after the section
"Things to Do".

Add a short section called "Travel Experience".

Maintain the same friendly tone and avoid repeating
previous points.
Result

The AI extends the article while maintaining the existing writing style.

8. Menu Actions Pattern
Prompt
The Ooty travel blog has been completed.

Choose the next action:

A. Add travel tips
B. Add a packing checklist
C. Make the article more formal
D. Shorten the article
E. Convert it into Instagram caption ideas

Select one suitable action.
Selected Action

B. Add a packing checklist

Result

The article becomes more useful for someone preparing for a trip.

9. Semantic Filter Pattern
Prompt
Rewrite the Ooty travel blog using these filters:

Audience: College students
Tone: Friendly and informative
Language: Simple English
Keep: Places, activities and practical tips
Remove: Repetition and exaggerated descriptions
Style: Short paragraphs with headings

## Final Version
# Scenario 1: Renewable Energy

Renewable energy comes from natural sources that are continuously replenished. Major sources include solar, wind, hydropower, biomass, and geothermal energy.

Renewable energy can reduce dependence on fossil fuels and support cleaner energy systems. However, challenges such as weather dependence, storage requirements, installation costs, and location requirements should also be considered.

Understanding both the advantages and limitations of renewable energy is important when studying future energy systems.

# Scenario 2: Ooty Travel Blog

Ooty is a popular hill station in Tamil Nadu known for its green landscapes, tea plantations, gardens, and scenic surroundings.

Visitors can explore places such as Ooty Lake, Botanical Garden, Doddabetta Peak, and tea-growing areas. Nature walks, sightseeing, photography, and exploring local food are some activities visitors may enjoy.

# Final Evaluation

The experiment demonstrates that changing the structure of a prompt can significantly affect AI-generated content.

A simple prompt produces a general response, while structured prompts provide better organization. Advanced prompt patterns allow the user to control the content, audience, tone, accuracy checks, and output format.

Therefore, Prompt Engineering can be used to create more coherent, relevant, structured, and useful content.

## Conclusion

This experiment demonstrated the use of different Prompt Engineering patterns for content generation.

Query Decomposition helped divide complex tasks into smaller steps. Decision Making helped select suitable options. Answer Engineering controlled the structure of the output. Fact Check Lists helped identify information that requires verification. Tail Generation extended existing content logically. Menu Actions provided different improvement choices, while Semantic Filtering controlled the tone, audience, and relevance of the generated content.

The experiment shows that carefully designed prompts can improve the clarity, organization, consistency, and usefulness of AI-generated content.
